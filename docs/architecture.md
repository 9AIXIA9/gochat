# GoChat 架构设计

## 设计目标
- 高并发实时通信
- 清晰的领域边界
- 可扩展的多通道支持
- 生产级别的可靠性

## 架构决策记录 (ADR)
这里记录关键架构决策，例如：

### ADR-001: 采用 DDD 分层架构
**状态**: 已采纳
**背景**: 业务复杂度上升，需要清晰的边界和可维护性
**决策**: 采用 DDD 分层（应用层/领域层/基础设施层/端口层）
**影响**: 增加了初始复杂度，但提升了长期可维护性
**相关代码**: `internal/` 目录结构

### ADR-002: 事件驱动架构
**状态**: 已采纳
**背景**: 需要解耦跨上下文通信
**决策**: 使用 Kafka 作为事件总线
**影响**: 增加了基础设施复杂度，但提升了可扩展性
**相关代码**: `internal/shared/event/`, `internal/delivery/kafka/`
